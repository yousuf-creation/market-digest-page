Why Your Claude Code Bill is So High (And How to Fix It)

Duncan Rogoff says four habits quietly raise Claude Code costs, and all four make Claude reread more of the chat than it needs to.

  • The four traps: using /compact like a diet, letting the cache expire, loading too much at the start (a long Claude.md, extra connectors), and keeping the default settings (Opus with thinking on).
  • The cache is short-term memory. Reads from it cost a tenth of the normal price or less. It lasts about an hour on a monthly plan and 5 minutes on pay-per-use. Switching models wipes it.
  • Output costs five times more than input. Keep Claude.md under 200 lines, pick Sonnet for building, and set a low effort for easy jobs.
  • What to do: use /clear when a job ends, or write a handoff doc. Stay on one model. Be specific in prompts. Type /usage today and again a week later to see if the number dropped.

"Every one of these four things comes from the same place, making Claude reread more than it has to."
