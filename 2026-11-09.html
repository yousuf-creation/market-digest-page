Simon Willison8 NovArticle
parse_number() as a SQLite extension: C vs Rust

Simon Willison used Claude to build a SQLite function that turns text like '-$1,234.56' into numbers, and found a tuned C version beat the Rust versions.

  • The first C extension was 14 KB. The Rust versions were 321 KB (Rusqlite) and 298 KB (sqlite-loadable-rs).
  • At first the Rust versions were faster, because Rust's number parser is "twice as fast" as C's strtod.
  • Claude then wrote a custom C number parser. Over 2 million rows it cost 16 to 19 ns per row, against 32 to 55 ns for Rust.
  • On decimals only, the first C took 106 ns. The new C took 18 ns.

"Try writing your own C function for parsing text into a decimal number that catches up to or beats the Rust implementation"

Simon Willison7 NovArticle
datasette #3046: Don't serve link: rel=next HTTP headers to Firefox for HTML pages

Simon Willison found that Firefox was quietly loading the next page of rows on Datasette table pages, and says Datasette should stop sending the header that causes it.

  • Simon Willison saw it in the Firefox network panel. Visits to a Datasette table page triggered a prefetch, which means loading the next page early, before anyone asks for it.
  • The cause is a link header marked rel="next" that Datasette pages send.
  • Simon Willison calls this bad. Only a tiny fraction of visitors click "next". The rest waste browser data, and the server renders a whole page that is thrown away.
  • Firefox has had an open issue about this behavior for 24 years. An early comment on it links to Simon Willison's own 2002 blog post complaining about the feature. They had forgotten the feature entirely.

"I hadn't just forgotten that I had written about it, I had forgotten the feature entirely!"

Rokas Golcas says lead-gen advertisers are bidding on the wrong thing

Writing in PPC Digest, Golcas argues that Google's Smart Bidding chases whatever conversion you count, so bidding on form fills just finds more form fills. His solar example: Campaign A has cheaper form fills but costs $2,000 per sale, while Campaign B costs about $433. The fix he describes is enhanced conversions for leads — sending hashed email or phone plus the click ID back from your CRM, through Data Manager or connectors like HubSpot and Salesforce. Deadlines: 90 days after the click with a click ID, 63 days with hashed data, uploaded daily. He says to make one conversion action per funnel stage, and only bid on one that has at least 15 conversions in 30 days.

Anthropic & OpenAI6 NovArticle
Measuring how ai agents handle wet lab science

OpenAI and the biotech firm Ligo made BioBasicsBench, a test of how well AI agents read raw data from everyday lab experiments, and found the newest model improved a lot but still makes errors.

  • The test has 100 tasks built from real lab data, such as gel images, colony plates, microscope images and instrument readouts. Each task is graded by an expert-written rubric.
  • At the highest reasoning setting, GPT-6 Astra scored 66.7% of the available credit. GPT-6.1 Sol scored 62.0%, GPT-5.6 Sol 43.8%, and GPT-5.2 31.2%.
  • Astra did better at spotting what the data cannot show, such as a control plate labeled with the wrong antibiotic. It also did better at reading images and keeping the experiment's context in mind.
  • Astra still let assumptions override the controls, ignored data that went against its view, and overcounted colonies by about 12%.

"Higher benchmark scores do not yet mean models can make reliable judgments in the lab."

Gergely Orosz5 NovArticle
Scaling slack and github with maude

Gergely Orosz shares eight takeaways from a podcast with engineer Maude Lemaire about the hard parts of scaling Slack and GitHub, and about using AI while keeping human judgment.

  • Slack limits custom emojis to 23. At 100,000 users, 10 emojis mean 1,000,000 fan-outs and 100 emojis mean 10,000,000. That is too much network load.
  • Testing 500,000 connections with headless Chrome would have cost $0.37 per five-hour session, per instance, or about $150,000 per run. Lemaire built Koi Pond, a slim Go tool, instead.
  • At GitHub, the home page often ran 100 SQL queries across three database clusters. Scatter queries kept GitHub from adding more than 16 database shards.
  • Lemaire checks all LLM output herself for foundational platform work. She also suggests platform and product engineers rotate teams.

"The best competition is competition with yourself, knowing that you can do better, knowing that you can drive a better experience"
