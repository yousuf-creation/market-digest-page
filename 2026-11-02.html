Simon Willison1 NovArticle
If in doubt, delete the uv.lock file

Simon Willison says that when a confusing Python error shows up after moving to Python 3.15, the fix is usually to delete the uv.lock file.

  • Simon has had odd dependency errors since he switched to Python 3.15.
  • Running uv run pytest leaves a uv.lock file behind. Sometimes it pins a version of a tool that has no Python 3.15 build yet.
  • His example: watchfiles 1.1.1 failed to build because Python 3.15 is newer than the highest version PyO3 supports, which is 3.14.
  • Most of his projects are libraries. They skip uv.lock because it is rude for a library to lock versions for others. The file is in .gitignore.
  • Deleting the file and running uv run pytest again usually fixes it.

"If in doubt, delete the uv.lock file"

How We Took Over ChatGPT Accounts

Simon Willison reports that Parameter Labs found a way to take over ChatGPT accounts by chaining several small flaws in how ChatGPT shows custom HTML apps.

  • The attack began in a locked-down box (a sandboxed iframe) that shows HTML previews. A math keyboard tool let that box send a message that put HTML into the main page.

  • With code running, the attacker could pull private data and send it out through an image link.
  • A ChatGPT share link could take data or act for any signed-in user who opened it.
  • OpenAI fixed the hole and paid a $5,000 bug bounty. Simon Willison thinks that was a bit cheap.

"The end result: you could create a ChatGPT share URL which, when visited by another signed-in user, could exfiltrate their private data or take actions on their behalf."
